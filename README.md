# لطیف تولز — ثبت‌نام، ورود و داشبورد

جعبه‌ابزار آنلاین لطیف تولز.

> 🌐 **نسخه دمو آنلاین (GitHub Pages):** https://mnazifi1184-droid.github.io/latif-tools/

## امکانات

### حساب کاربری واقعی
- **ثبت‌نام** با نام کاربری و رمز عبور (بدون نیاز به ایمیل)
- **ورود** با نام کاربری و رمز
- **تغییر رمز عبور** از داخل داشبورد (با تأیید رمز فعلی)
- رمزها با **scrypt + salt تصادفی** هش می‌شوند؛ هرگز به‌صورت متن ساده ذخیره نمی‌شوند
- دیتابیس **SQLite** (`latif.db`) — ساخته‌شدن خودکار در اولین اجرا
- محافظت از مسیر داشبورد با سشن؛ خروج با یک کلیک

### داشبورد (بعد از ورود)
- محاسبه‌گر سریع، فرمت‌کن متن، مبدل واحد، تولید رمز عبور قوی، Base64
- **تغییر رمز عبور** (ابزار ششم)
- نمودار فعالیت هفت روز گذشته (Chart.js — self-host)
- شمارنده عملیات نشست، اعلان‌های Toast

### صفحه ورود
- طراحی شیشه‌ای (Glassmorphism)، تم شبانه، هاله‌های نورانی، RTL، فونت وزیرمتن
- تب «ورود» و «ثبت‌نام»، نمایش/مخفی‌کردن رمز، ریسپانسیو کامل

## اجرا

```bash
pip install -r requirements.txt
python app.py
# → http://localhost:8000
```

## API

| متد  | مسیر                  | توضیح |
|------|-----------------------|-------|
| POST | `/api/register`       | ثبت‌نام (`{username, password}`) |
| POST | `/api/login`          | ورود (`{username, password}`) |
| POST | `/api/change-password`| تغییر رمز — نیازمند سشن (`{current, new}`) |
| POST | `/api/logout`         | خروج |
| GET  | `/dashboard`          | داشبورد (نیازمند سشن) |
| GET  | `/healthz`            | بررسی سلامت |

- نام کاربری: ۳ تا ۲۰ کاراکتر انگلیسی/عدد/`.`/`_`
- رمز عبور: حداقل ۸ کاراکتر

> **نسخه استاتیک (Pages):** سروری ندارد؛ ثبت‌نام/ورود/تغییر رمز در مرورگر با
> localStorage شبیه‌سازی می‌شود — فقط برای دمو. تجربه واقعی با `python app.py`.
