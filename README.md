# لاتیف تولز — صفحه ورود و داشبورد

جعبه‌ابزار آنلاین لاتیف تولز.

> 🌐 **نسخه دمو آنلاین (GitHub Pages):** https://mnazifi1184-droid.github.io/latif-tools/

## امکانات

### صفحه ورود
- کارت شیشه‌ای (Glassmorphism) با تم شبانه، هاله‌های نورانی و پس‌زمینه شبکه‌ای
- ورود با **رمز عبور** — با شماره موبایل **یا** ایمیل
- ورود با **کد یکبارمصرف ایمیلی** (OTP) دو مرحله‌ای با تایمر ۲ دقیقه‌ای و ارسال مجدد
- پشتیبانی کامل از اعداد فارسی/عربی در ورودی‌ها
- نمایش/مخفی‌کردن رمز، پیام‌های خطای واضح، حالت لودینگ دکمه‌ها
- کاملاً ریسپانسیو (تست‌شده تا عرض ۳۹۰ پیکسل)، RTL، فونت وزیرمتن

### داشبورد (بعد از ورود)
- محاسبه‌گر سریع، فرمت‌کن متن، مبدل واحد، تولید رمز عبور قوی، Base64
- نمودار فعالیت هفت روز گذشته (Chart.js)
- شمارنده عملیات نشست، محافظت از مسیر (بدون ورود → برگشت به لاگین)، خروج

## اجرا

```bash
pip install -r requirements.txt
python app.py
# → http://localhost:8000
```

## API

| متد  | مسیر               | توضیح |
|------|--------------------|-------|
| POST | `/api/login`       | ورود با رمز — شماره یا ایمیل (`{identifier, password}`) |
| POST | `/api/otp/request` | ارسال کد یکبارمصرف به ایمیل (`{email}`) |
| POST | `/api/otp/verify`  | تایید کد (`{email, code}`) |
| POST | `/api/logout`      | خروج از حساب |
| GET  | `/dashboard`       | داشبورد (نیازمند سشن) |
| GET  | `/healthz`         | بررسی سلامت سرویس |

> **حالت دمو:** کد OTP در پاسخ `/api/otp/request` برگردانده می‌شود تا فلو قابل تست باشد.
> قبل از استقرار واقعی: این فیلد حذف شود و ارسال ایمیل با SMTP جی‌میل (App Password)
> یا سرویس ایمیل (مثل Resend) پیاده‌سازی شود؛ همچنین هش رمز و دیتابیس اضافه شود.
