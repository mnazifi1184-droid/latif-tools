# لاتیف تولز — صفحه ورود

جعبه‌ابزار آنلاین لاتیف تولز — فاز اول: صفحه ورود (Login).

## امکانات این فاز

- صفحه ورود شیشه‌ای (Glassmorphism) با تم شبانه، هاله‌های نورانی و پس‌زمینه شبکه‌ای
- ورود با **رمز عبور** (اعتبارسنجی سمت کلاینت و سرور)
- ورود با **کد یکبارمصرف (OTP)** دو مرحله‌ای با تایمر ۲ دقیقه‌ای و ارسال مجدد
- پشتیبانی کامل از اعداد فارسی/عربی در ورودی‌ها
- نمایش/مخفی‌کردن رمز، پیام‌های خطای واضح، حالت لودینگ دکمه‌ها
- کاملاً ریسپانسیو (تست‌شده تا عرض ۳۹۰ پیکسل)، RTL، فونت وزیرمتن (self-host)
- رعایت `prefers-reduced-motion` و فوکوس کیبورد

## اجرا

```bash
pip install -r requirements.txt
python app.py
# → http://localhost:8000
```

## API

| متد  | مسیر               | توضیح |
|------|--------------------|-------|
| POST | `/api/login`       | ورود با رمز (`{phone, password}`) |
| POST | `/api/otp/request` | درخواست کد یکبارمصرف (`{phone}`) |
| POST | `/api/otp/verify`  | تایید کد (`{phone, code}`) |
| GET  | `/healthz`         | بررسی سلامت سرویس |

> **حالت دمو:** کد OTP در پاسخ `/api/otp/request` برگردانده می‌شود تا بتوان فلوی ورود را تست کرد.
> قبل از استقرار واقعی، این فیلد حذف و پیامک‌رسان واقعی (Kavenegar، SMS.ir و…) جایگزین شود.
